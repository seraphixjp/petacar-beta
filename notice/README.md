# 公式からのお知らせ（アプリの審査なしで変更できる）

マイスタンプのタイトルの下に1行の帯で表示されます。長い文は横に流れます。

- `app.json` … 本番（ストアのアプリ・Web本番）
- `test.json` … テストURL・試作版

```json
{"items":[
  {"id":"2026-11-19a","text":"お知らせ本文","from":"2026-11-19","to":"2026-11-30","url":"https://…（任意）","lv":"info"}
]}
```

- `id`：お知らせごとに変える（× で閉じたかどうかを id で覚える）
- `from`〜`to`：表示する期間（日本の日付・省略可）
- `url`：押したときに開くページ（https のみ・省略すると全文を表示）
- `lv`：`info`（オレンジ）／`warn`（赤）
- 複数あれば12秒ごとに切り替え。反映はアプリを開いたとき・戻ってきたとき（30分おき）。GitHub Pages の反映に数分かかることがあります
